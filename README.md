1.Git คือระบบควบคุมเวอร์ชันของไฟล์ ช่วยบันทึกการเปลี่ยนแปลงและย้อนกลับไปดูเวอร์ชันก่อนหน้าได้

2.การทำงาน เว็บไซต์ทำงานโดยผู้ใช้เปิดเว็บเบราว์เซอร์และส่งคำขอไปยังเซิร์ฟเวอร์ จากนั้นเซิน์ฟเวอร์จะส่งข้อมูลกลับมาแสดงผลบนหน้าเว็บไซต์

3. เว็บไซต์แตกต่างจากแอพพลิเคชั่นอย่างไรเว็บแอพพลิเคชั่น (Web Application) เน้นให้ผู้ใช้งานมีปฏิสัมพันธ์และทำกิจกรรมหรือทำงานได้จริง (ให้คนเข้ามา "ใช้งาน" หรือประมวลผลข้อมูล)


4.คู่มือการใช้งาน GitHub
1.สมัครสมากชิกที่ GitHub
2.เข้าสู่ระบบ
3.สร้าง Repository เพื่อเก็บไฟล์งาน
4.เพื่มไฟล์และเขียนรายละเอียดใน README.md
5.บันทึกการเปลี่ยนแปลงไฟล์
6.แชร์ลิ้งก์ Repository ให้ผู้อื่นเข้าชม
